# Проверка ProCam 17 на устройстве

Статус на момент передачи: сценарии **не выполнены**. Нужны реальный Android
и первый успешный CI-прогон. Предпочтительно Android 8/9 и Android 13/14+.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Чистая установка, доступ к камере разрешён | Есть превью, работает затвор |
| Доступ к камере отклонён | Нет вылета, доступна галерея |
| Доступ отклонён навсегда → «Доступ» | Открываются настройки приложения |
| Разрешение выдано в настройках → возврат | Появляется превью |
| Устройство без камеры | Сообщение и доступная галерея |
| Смена фронтальной/задней | Переключается камера, если обе доступны |
| Касание превью | Запрос автофокусировки |
| Изменить свет/цвет/детали до зйомки | Изменение видно в live-превью |
| Пресет «Портрет» до съёмки | В live размывается фон человека; проверить границы |
| Фронтальная камера, live | Ориентация правильная, превью зеркальное |
| Смена камеры во время live | Нет старых кадров от другой камеры |
| Камера не поддерживает три потока | Обычное превью с пояснением; затвор работает |
| 5 минут live с портретом | Измерить плавность, нагрев и расход памяти |
| Одиночная съёмка | Открывается результат, обработка заканчивается |
| HDR включён, статичная контрастная сцена | Три экспозиции и один результат |
| HDR включён, человек двигается | Откат либо подавление двоения; проверить артефакты |
| HDR на камере без компенсации | Один кадр и пояснение |
| Галерея: отменить выбор | Текущая фотография сохраняется |
| Галерея: большой JPEG 48–108 МП | Загрузка без OOM, длинная сторона ≤2048 |
| EXIF 1–8, включая зеркальные | Правильная ориентация |
| HEIC / PNG | Поддерживаемый системой формат открывается либо понятная ошибка |
| Повреждённое фото / отозванный URI | Понятная ошибка, кнопки снова доступны |
| Все регуляторы 0 | Без HDR-серии результат соответствует декодированному оригиналу |
| Изменить регулятор | До применения сохранение недоступно |
| Применить настройки | Результат меняется, сохранение доступно |
| Пресеты | Значения регуляторов и результат соответствуют пресету |
| Портрет с человеком | Фон размыт, лицо/тело преимущественно резкие |
| Портрет без человека | Пояснение, нет тотального размытия |
| Удержание фото / отпускание / отмена касания | Переключение оригинал/результат |
| Быстрые многократные нажатия | Нет параллельных обработок |
| Сохранение Android 10+ | JPEG в Pictures/ProCam17 без разрешения хранилища |
| Сохранение Android 8–9 | Запрос записи, после разрешения JPEG в галерее |
| Запрет записи / заполненный диск | Нет ложного «Сохранено», нет пустого JPEG |
| Свернуть при съёмке / обработке | Нет падения; при отмене съёмки доступно повторение |
| Вернуться в камеру из редактора | Камера снова работает |
| Небольшой экран / увеличенный шрифт | Элементы доступны прокруткой |
| 20 последовательных загрузок и сохранений | Нет устойчивого роста памяти до падения |

Артефакты при проблеме: модель телефона, Android, точные действия, пример
исходного фото без чувствительных данных и `adb logcat -b crash -d`.
Для компиляции — журнал конкретного упавшего шага GitHub Actions.
